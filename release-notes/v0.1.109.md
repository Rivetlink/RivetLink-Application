Security fixes
- Connecting to your server over a secure (https) address now works. Before, a computer could not reach a relay that uses an https address, such as the one from the RivetLink-Docker setup.
- Server (relay image 0.1.109): stronger protection against password guessing, a limit on how many computers one account can register, smaller limits on request and message sizes, and old login and audit records are cleaned up automatically.
- The server refuses to start with the example password secret from the documentation.
